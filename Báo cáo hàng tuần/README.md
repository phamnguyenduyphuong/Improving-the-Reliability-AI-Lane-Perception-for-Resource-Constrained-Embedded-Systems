# Báo cáo tiến độ hàng tuần

Thư mục này lưu trữ báo cáo tiến độ hàng tuần của đồ án:

**Cải thiện độ tin cậy của nhận thức làn đường dựa trên AI cho các hệ thống nhúng hạn chế tài nguyên**

**Ứng dụng cho robot giao hàng tự hành**

## Tiến độ thực hiện

| Tuần | Nội dung chính | Trạng thái |
|---|---|---|
| [Week 1](./week1/) | Khảo sát đề tài và xây dựng ý tưởng hệ thống ban đầu | ✅ Hoàn thành |
| Week 2 | Khảo sát bài báo và xác định hướng nghiên cứu | ✅ Hoàn thành |
| Week 3 | Triển khai và benchmark mô hình trên Raspberry Pi | ✅ Hoàn thành |

## Cấu trúc báo cáo

Mỗi thư mục tuần bao gồm:

- `README.md`: tóm tắt mục tiêu, công việc, kết quả, vấn đề và hướng tiếp theo.
- Slide/PDF dùng để báo cáo.
- Hình ảnh, video hoặc dữ liệu thực nghiệm nếu có.
- Source code hoặc script liên quan nếu tuần đó có triển khai.
